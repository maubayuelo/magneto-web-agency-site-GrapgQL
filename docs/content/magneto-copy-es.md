## 2. Introducción

### Empezar por el problema, no por el paquete.

Magneto ayuda a las empresas de servicios de Montreal a elegir la solución más sensata para su sitio web.

Puede tratarse de crear un sitio nuevo, corregir problemas específicos de uno existente o darle mantenimiento continuo una vez que esté estable.

Los tres servicios principales son **BUILD, FIX y CARE**.

## Los tres servicios principales

### 3. BUILD — Creación y rediseño de sitios web

#### Un sitio web que facilita que tus visitantes entiendan tu negocio, confíen en él y se comuniquen contigo.

BUILD está pensado para empresas que necesitan un sitio web nuevo, un rediseño importante o una página de destino específica.

El trabajo integra estrategia, estructura, diseño UX/UI y desarrollo para que el resultado sea una experiencia web coherente.

**Según el proyecto, el alcance puede incluir:**

- Estrategia web y estructura del contenido
- Diseño UX/UI
- Desarrollo adaptable a distintos dispositivos
- Sistema de gestión de contenido (CMS), cuando sea necesario
- Formularios, reservas e integraciones habituales
- Implementación multilingüe, cuando se requiera
- Bases de analítica y posicionamiento en buscadores
- Control de calidad, lanzamiento y entrega al cliente

**Inversión:** desde **3 500 CAD** por una página de destino específica en un solo idioma. Inversión habitual para un sitio web: **5 000–8 000 CAD**. Proyectos a medida: **10 000 CAD o más**. Todos los precios están expresados en dólares canadienses. Se añaden los impuestos aplicables cuando corresponda.

**CTA: Ver precios de BUILD**

### 4. FIX — Optimización y recuperación de sitios web

#### Mejora el sitio web que ya tienes, sin rehacerlo innecesariamente.

FIX está pensado para sitios que funcionan en lo esencial, pero tienen problemas específicos que afectan su claridad, facilidad de uso o confiabilidad.

Por ejemplo: una experiencia confusa en dispositivos móviles, páginas lentas, formularios o reservas que fallan, problemas con WordPress u otros aspectos técnicos, dificultades con la analítica, bases de accesibilidad por mejorar u otros obstáculos técnicos.

Magneto sigue un proceso sencillo:

**Diagnosticar → Priorizar → Aprobar → Corregir → Verificar**

Sabes qué se va a corregir antes de empezar el trabajo y el resultado se verifica al terminar.

**Algunas intervenciones habituales de FIX son:**

- Problemas en dispositivos móviles y de usabilidad
- Fallas en formularios y sistemas de reservas
- Mejoras de rendimiento
- Problemas con WordPress u otros aspectos técnicos
- Configuración o corrección de la analítica
- Bases de accesibilidad
- Problemas de confiabilidad técnica

La mayoría de los problemas bien delimitados pueden pasar directamente a una cotización FIX. Si el sitio necesita una revisión técnica más profunda para definir responsablemente el alcance de los trabajos, puede recomendarse primero un **Diagnóstico pagado del sitio web**.

**CTA: Ver cómo funciona FIX**

### 5. CARE — Mantenimiento de sitios web

#### Mantén tu sitio web actualizado, supervisado y con soporte continuo.

CARE ofrece soporte continuo para sitios web que ya se encuentran en buenas condiciones de funcionamiento.

Según el plan, CARE puede incluir mantenimiento habitual, supervisión, verificación de formularios críticos o procesos de reserva, revisión del estado del sitio, pequeños cambios y soporte web continuo.

Los sitios desarrollados por Magneto pueden pasar a CARE después de su lanzamiento, cuando sea apropiado. Si el sitio existente no fue desarrollado por Magneto, se requiere un **Diagnóstico pagado del sitio web antes de su aceptación en CARE**. Es posible que los problemas existentes deban estabilizarse primero mediante FIX.

**CTA: Comparar los planes CARE**

### 6. Páginas de destino específicas

#### Un público. Una oferta. Un siguiente paso claro.

Una página de destino específica es un **proyecto BUILD** para un servicio, una campaña o una oferta concreta, cuando no hace falta desarrollar un sitio web completo.

Puede incluir una estructura de página enfocada, diseño UX/UI orientado hacia un siguiente paso claro, formularios o reservas, bases de analítica e implementación multilingüe cuando se necesite.

Estas páginas pueden recibir visitantes que llegan por recomendación, desde buscadores o a través de campañas publicitarias pagadas. Magneto desarrolla la página; **la gestión de campañas publicitarias no está incluida**.

### 7. Sitios web multilingües

#### Comunica tu oferta con claridad en español, francés e inglés.

La implementación multilingüe puede incluir la adaptación de textos web ya aprobados entre español, francés e inglés cuando esté contemplada en el alcance del proyecto.

Magneto puede estructurar y desarrollar experiencias multilingües y mantener la coherencia de la navegación, la jerarquía del contenido y los llamados a la acción entre idiomas.

La cantidad de idiomas influye en la complejidad del proyecto y se evalúa como parte del trabajo BUILD, FIX o CARE correspondiente.

**No se incluyen traducciones certificadas ni especializadas.** El cliente debe aprobar la versión final de los textos adaptados.

### 8. Reservas, formularios y captación de contactos

#### Facilita que el visitante adecuado dé el siguiente paso.

Según las necesidades de tu negocio, el sitio web puede conectar a tus visitantes con formularios de contacto, sistemas de reservas, Calendly, suscripciones al boletín informativo o captación de correos electrónicos, WhatsApp y otros canales habituales para enviar consultas.

El objetivo no es añadir herramientas por añadirlas. El recorrido adecuado depende de lo que el visitante necesite hacer después.

### 9. Bases de analítica, posicionamiento en buscadores y accesibilidad

#### Dale a tu sitio web las bases técnicas que necesita para funcionar de manera responsable.

Cuando el proyecto lo requiera, Magneto puede incluir configuración de analítica, bases de SEO y de accesibilidad, configuración del sistema de gestión de contenido (CMS) e integraciones habituales con servicios de terceros.

La automatización avanzada, los sistemas de inteligencia artificial, el comercio electrónico complejo, la lógica de aplicaciones a medida o una infraestructura poco habitual requieren una evaluación por separado y podrían convertirse en un proyecto a medida.
